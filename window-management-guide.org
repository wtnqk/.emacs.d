* はじめに

Emacs では、画面を分割して複数のファイルやバッファを同時に見ながら作業できます。このガイドでは *この Emacs の実際の設定*（~/.emacs.d/init.el）にもとづいて、ウィンドウの分割・移動・サイズ調整・ファイルツリー・タブ管理の操作方法を解説します。

主な機能と対応ツールは次の通りです。

- 分割: Emacs 標準の =C-x 2= / =C-x 3=
- 移動: ace-window（=C-x o=）
- 分割履歴の取り消し: winner-mode（=C-c <left>= / =C-c <right>=）
- 一時最大化: zoom-window（=C-c C-z=）
- ファイルツリー: treemacs（=C-q=）
- タブ管理: tab-bar（=C-x C-t=）
- 候補を分割して開く: Embark（=C-.= の =o= / =2= / =3=）

キーバインドはすべてこの Emacs の init.el で実際に設定されているものです。

* 前提: バッファ・ウィンドウ・フレーム・タブの関係

ウィンドウ管理を理解するには、次の4つの概念を区別すると分かりやすいです。

| 概念 | 日本語 | 説明 |
|------|--------|------|
| バッファ (buffer) | 編集対象のテキスト | 開いたファイルの中身そのもの。裏側に無数に存在する |
| ウィンドウ (window) | 表示領域 | バッファを「見るための窓」。1つのフレーム内に複数作れる。*分割の単位* |
| フレーム (frame) | OS上のウィンドウ | Emacs 全体の外枠。通常は1つ |
| タブ (tab) | ウィンドウ構成の切替 | フレーム内のウィンドウの組み合わせ（レイアウト）をタブで管理 |

特に重要なのは「*同じバッファを複数のウィンドウに同時に表示できる*」点です。バッファはデータ、ウィンドウはその見せ方なので、ウィンドウを閉じても（=C-x 0=）バッファは消えません。

* 分割する

分割がウィンドウ管理の基本です。既定の分割コマンドをそのまま使います。

#+BEGIN_EXAMPLE
C-x 2   ;; 縦に分割（ウィンドウが上下に並ぶ）
C-x 3   ;; 横に分割（ウィンドウが左右に並ぶ）
#+END_EXAMPLE

- =C-x 2= は「上下に積む」= 縦分割
- =C-x 3= は「左右に並べる」= 横分割

閉じる操作は次の通りです。

#+BEGIN_EXAMPLE
C-x 0   ;; 現在のウィンドウを閉じる（バッファは残る）
C-x 1   ;; 現在のウィンドウだけ残して他を閉じる
#+END_EXAMPLE

* ウィンドウ間を移動する

** ace-window による移動（=C-x o=）

この Emacs では、標準の「次のウィンドウへ」（元の =C-x o=）を *ace-window* に置き換えています。

#+BEGIN_EXAMPLE
C-x o   ;; ace-window を起動
#+END_EXAMPLE

ace-window が起動すると、各ウィンドウに文字が重なって表示されます。表示された文字（=a s d f g h j k l=）を押すと、そのウィンドウへ即座に移動できます。

- 使えるキー: =a s d f g h j k l=（ホーム列を中心に選択）
- 対象範囲: 現在のフレーム内（=aw-scope= を =frame= に設定）

** winner-mode による分割の取り消し（=C-c <left>= / =C-c <right>=）

分割やサイズ変更をやり直したいときは winner-mode を使います。

#+BEGIN_EXAMPLE
C-c <left>    ;; 直前のウィンドウ構成に戻す（undo）
C-c <right>   ;; 取り消した構成を再適用（redo）
#+END_EXAMPLE

分割を戻したり、再度進めたりしながら、望むレイアウトに微調整できます。

* サイズを調整する

Emacs 標準のサイズ変更コマンドを使います。

#+BEGIN_EXAMPLE
C-x ^   ;; 現在のウィンドウの高さを広げる（縦方向）
C-x }   ;; 現在のウィンドウの幅を広げる（横方向）
C-x {   ;; 現在のウィンドウの幅を狭める
C-x +   ;; 全ウィンドウを等サイズに揃える
#+END_EXAMPLE

分割した後、作業中のウィンドウを広げたいときは =C-x ^= / =C-x }= が便利です。=C-x += で全体を整えます。

* 現在のウィンドウを一時的に最大化する（=C-c C-z=）

分割作業で、いま見ているウィンドウだけを一時的に大きくしたいときに使います。

#+BEGIN_EXAMPLE
C-c C-z   ;; 現在のウィンドウを最大化（再度押すと元の構成に戻る）
#+END_EXAMPLE

zoom-window は「tmux の zoom/unzoom」のように、*元のウィンドウ構成を記憶して*一時的に最大化し、もう一度押すと元に戻します。

* ファイルツリーを表示する（treemacs）

右側サイドバーのファイルツリーは *treemacs* で開閉します。

#+BEGIN_EXAMPLE
C-q   ;; treemacs を開く／閉じる（トグル）
#+END_EXAMPLE

この Emacs での設定は次の通りです。

- 右側に表示する（=treemacs-width= 50）
- 編集中のバッファにツリーが自動追従する（follow-mode）
- プロジェクトに自動追従する（project-follow-mode）
- ファイルの変更を自動監視する（filewatch-mode）
- Git の状態（変更・未追跡など）を色で表示する（=treemacs-git-mode= を =deferred= に設定）

=deferred= の Git モードは、初期表示を高速化しつつ後から Git 状態を反映するため、大きいプロジェクトでも快適に動作します。

* タブでワークスペースを管理する（tab-bar）

タブを使うと、フレーム内のウィンドウ構成をプロジェクト単位で切り替えられます。

#+BEGIN_EXAMPLE
C-x C-t   ;; タブ・バーを操作する
#+END_EXAMPLE

= C-x C-t= の後の代表的な操作は次の通りです。

| キー | 操作 |
|------|------|
| =t= | 新しいタブを作る |
| =n= | 次のタブへ |
| =p= | 前のタブへ |
| =r= | 現在のタブをリネーム |
| =0= | 現在のタブを閉じる |

タブはこの Emacs では*プロジェクト名で自動的に命名*されます（project.el のプロジェクト名を使用）。文字数が長すぎる場合は省略されます（=tab-bar-tab-name-truncated-max= 12）。

** treemacs と tab-bar の連携

この設定では、treemacs は*タブごとに独立*しています（treemacs-tab-bar の =Tabs= スコープ）。

つまり、タブを切り替えると、そのタブに対応するプロジェクトのツリーが表示されます。プロジェクト A のタブにはプロジェクト A のツリー、プロジェクト B のタブにはプロジェクト B のツリーがそれぞれ独立して維持されます。

- タブを切り替えると、右側の treemacs もそのタブのツリーに切り替わります
- 各タブ内で treemacs を開いた状態（開いているか閉じているか）もタブごとに独立します

* 候補を選んだウィンドウへ開く（Embark）

バッファ・ファイル・ブックマークの候補に対して =C-.= で Embark を起動し、開き先を指定できます。

#+BEGIN_EXAMPLE
C-.   ;; Embark を起動（候補に対して）
o     ;; ace-window で任意のウィンドウを選んで開く
2     ;; 下に分割して開く
3     ;; 右に分割して開く
#+END_EXAMPLE

たとえば =C-x b= でバッファ候補を表示し、=C-.= を押すと、続けて =o=（任意ウィンドウへ）、=2=（下に分割）、=3=（右に分割）を選べます。ファイルやブックマークの候補でも同様です。

* よくある操作シナリオ

** 2画面でコードと結果を見比べる

#+BEGIN_EXAMPLE
;; 1. 現在のバッファを右に分割して別ファイルを開く
C-x 3
;; 2. 分割して開いた側でtreemacsなどからファイルを選ぶ（または C-x b）
;; 3. ace-window で左右を往復
C-x o   ;; 左のウィンドウを選ぶ（文字キー）
C-x o   ;; 右のウィンドウを選ぶ（文字キー）
#+END_EXAMPLE

** 3画面レイアウトを作って戻す

#+BEGIN_EXAMPLE
;; 縦に分割 → 右をさらに縦に分割 → 3画面
C-x 2
C-x 3
;; 一時的に1画面にして集中
C-c C-z
;; 元の3画面に戻す
C-c C-z
;; 履歴でさらに古い分割に戻す
C-c <left>
#+END_EXAMPLE

** プロジェクト単位でタブを使い分ける

#+BEGIN_EXAMPLE
;; 新しいタブを作る
C-x C-t t
;; そのタブでプロジェクトのファイルを開く
C-x b   ;; または treemacs から選ぶ
;; タブを行き来すると treemacs も各プロジェクトのツリーに切り替わる
C-x C-t n   ;; 次のタブ
#+END_EXAMPLE
